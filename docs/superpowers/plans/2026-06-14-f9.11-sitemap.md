# F9.11 Dynamic Sitemap per Portfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate a dynamic `sitemap.xml` for each portfolio using Next.js 15's `sitemap.ts` convention, served at `[subdomain].korp-cbm.com/sitemap.xml`. Only published portfolios are included. Uses `customDomain` if configured, otherwise falls back to `{slug}.korp-cbm.com`.

**Architecture:** A single `platform/src/app/(portfolio)/sitemap.ts` file exports a default async function (`MetadataRoute.Sitemap`). It reads the portfolio slug from the `x-portfolio-slug` header (set by middleware — same pattern used by `generateMetadata`), fetches the portfolio, checks `isPublished`, and returns a one-item sitemap with the portfolio's canonical URL. Section anchors (`#about`, `#contact`) are intentionally excluded — Google ignores URL fragment identifiers in sitemaps.

**Tech Stack:** Next.js 15 `MetadataRoute.Sitemap`, `next/headers`, existing `getPortfolioBySlug`

---

## Context

**Portfolios collection fields relevant to this task:**
- `subdomain: string` — slug used in URL (e.g. `radek`)
- `customDomain?: string` — optional custom domain (e.g. `radoslaw.pl`)
- `isPublished: boolean` — only published portfolios should appear in sitemap

**`NEXT_PUBLIC_PLATFORM_DOMAIN`** env var = `"korp-cbm.com"` (defined in `.env.local`)

**Middleware sets `x-portfolio-slug` header** — same as `generateMetadata` and page components use. So the sitemap function reads slug via `(await headers()).get("x-portfolio-slug")`.

**Next.js 15 sitemap convention:** A file named `sitemap.ts` in a route directory exports a default function returning `MetadataRoute.Sitemap`. Next.js automatically serves it at `/sitemap.xml` for that route.

```ts
// platform/src/app/(portfolio)/sitemap.ts
import type { MetadataRoute } from "next";
import { headers } from "next/headers";
import { getPortfolioBySlug } from "@/lib/portfolio";

const PLATFORM_DOMAIN =
  process.env.NEXT_PUBLIC_PLATFORM_DOMAIN ?? "korp-cbm.com";

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const slug = (await headers()).get("x-portfolio-slug");
  if (!slug) return [];

  const portfolio = await getPortfolioBySlug(slug);
  if (!portfolio || !(portfolio.isPublished as boolean | undefined)) return [];

  const baseUrl = (portfolio.customDomain as string | undefined)
    ? `https://${portfolio.customDomain as string}`
    : `https://${slug}.${PLATFORM_DOMAIN}`;

  return [
    {
      url: baseUrl,
      lastModified: new Date(),
      changeFrequency: "monthly",
      priority: 1,
    },
  ];
}
```
