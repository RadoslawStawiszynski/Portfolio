# Theme List

Krótki komentarz: poniżej masz 4 palety gotowe do wdrożenia w tokenach CSS (`background`, `text`, `accent`, `button`) dla trybu `light` i `dark`.

## 1) Pastelowa Elegancja

Kiedy używać: bezpieczny wybór startowy do kobiecej, ciepłej wizytówki autorskiej.

### Light

| Token | Kolor | Opis |
|---|---|---|
| `background` | `#F8F3F3` | Bardzo jasny róż |
| `text` | `#4B4B4B` | Ciemny szary |
| `accent` | `#F9AFAE` | Delikatny koral |
| `button` | `#FF6F61` | Czerwono-pomarańczowy |

### Dark

| Token | Kolor | Opis |
|---|---|---|
| `background` | `#2E2E2E` | Ciemny szary |
| `text` | `#F4F4F4` | Bardzo jasny szary |
| `accent` | `#FFB6B6` | Delikatny róż |
| `button` | `#D67A7A` | Pastelowy róż |

## Notatka wdrożeniowa

- Dla v1 rekomendacja: `Pastelowa Elegancja` jako domyślna (`light` + `dark`).
- W panelu admin zapisujemy każdą paletę jako rekord `ThemePalette` i oznaczamy jedną aktywną na tryb.
