- Plik `not-found.tsx` w segmencie trasy jest automatycznie wyświetlany gdy `notFound()` jest wywołany w tym segmencie lub zagnieżdżonych segmentach

- Layout wrappujący jest renderowany normalnie — `(portfolio)/layout.tsx` ustawi `data-theme` jeśli slug jest znany z nagłówka middleware

**Miejsca wywołania `notFound()` w projekcie:**
- `platform/src/app/(portfolio)/page.tsx:35` — gdy portfolio ze slug z nagłówka nie istnieje

```

```
Gdy brak `data-theme` (np. błędny subdomain bez pasującego portfolio), obowiązuje `:root` (light theme).

**Istniejące pliki nie-znaleziono w projekcie:** brak — Next.js używa domyślnej strony 404.

```tsx
// platform/src/app/(portfolio)/not-found.tsx
import { headers } from "next/headers";

const PLATFORM_DOMAIN =
  process.env.NEXT_PUBLIC_PLATFORM_DOMAIN ?? "korp-cbm.com";

export default async function NotFound() {
  const slug = (await headers()).get("x-portfolio-slug");

  return (
    <main className="flex min-h-screen flex-col items-center justify-center px-6 text-center bg-[var(--color-bg)]">
      <p className="mb-4 text-sm font-semibold uppercase tracking-widest text-[var(--color-accent)]">
        404
      </p>
      <h1 className="text-5xl font-bold text-[var(--color-primary)] md:text-7xl">
        Nie znaleziono
      </h1>
      <p className="mt-4 max-w-md text-lg text-[var(--color-muted)]">
        {slug
          ? `Portfolio "${slug}" nie istnieje lub nie jest opublikowane.`
          : "Ta strona nie istnieje."}
      </p>
      <div className="mt-8 flex flex-wrap justify-center gap-4">
        {slug && (
          <a
            href="/"
            className="rounded-full bg-[var(--color-accent)] px-6 py-3 text-sm font-semibold text-[var(--color-bg)] shadow hover:opacity-90 transition-opacity"
          >
            Strona główna
          </a>
        )}
        <a
          href={`https://${PLATFORM_DOMAIN}`}
          className="rounded-full border border-[var(--color-bg-alt)] px-6 py-3 text-sm font-semibold text-[var(--color-text)] hover:bg-[var(--color-bg-alt)] transition-colors"
        >
          PortfolioHub →
        </a>
      </div>
    </main>
  );
}
```

**Wyjaśnienie logiki:**
- `slug` z `x-portfolio-slug` nagłówka: jeśli jest → komunikat o konkretnym portfolio; jeśli brak → generyczny komunikat
- "Strona główna" CTA (link do `/`) pojawia się tylko gdy `slug` jest znany (bo subdomain portfolio ma swój root)
- "PortfolioHub →" link do `https://${PLATFORM_DOMAIN}` — zawsze widoczny, prowadzi do landing page platformy
- `bg-[var(--color-bg)]` na `<main>` — zapewnia tło nawet jeśli `<body>` nie ma ustawionego koloru
