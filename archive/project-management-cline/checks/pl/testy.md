---
name: Testy i Pokrycie
description: Wymaga testów dla nowej lub zmienionej logiki biznesowej
---

Przejrzyj pull request pod kątem jakości testów.

Oznacz jako NIEZALICZONE jeśli:
- Nowa lub zmieniona logika biznesowa bez towarzyszących testów jednostkowych/integracyjnych
- Testy sprawdzają tylko happy path (brak edge cases i przypadków błędów)
- Testy mockują za dużo (nie testują rzeczywistego zachowania)
- Niskie pokrycie na nowo dodanym kodzie

Jeśli testy są dobre — zaproponuj ulepszenia jeśli jakieś widzisz.
